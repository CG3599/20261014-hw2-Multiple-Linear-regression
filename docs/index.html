CRISP-DM / SIX PHASES

實驗方法 · CRISP-DM 六大階段

Cross-Industry Standard Process for Data Mining（跨產業資料探勘標準流程）。兩個資料集使用同一分析框架，細節以各自的資料與實驗設定為準。

01 / BUSINESS UNDERSTANDING

商業理解 · Business Understanding

以 Toyota Corolla 汽車規格估計售價（Price，歐元），觀察哪些車況與配備可能影響價格，並比較減少特徵是否能保留預測能力。

02 / DATA UNDERSTANDING

資料理解 · Data Understanding

資料來源為 ToyotaCorolla.csv：原始 1,436 筆，去除重複後 1,435 筆。輸入特徵共 33 個（31 個數值、fuel_type 與 color 兩個類別），Price 是預測目標，不列入特徵。

03 / DATA PREPARATION

資料準備 · Data Preparation

排除 model、cylinders、mfg_month、mfg_year；保留正價格樣本。數值以中位數、類別以眾數補值；cc、weight、hp 依訓練折 0.5%–99.5% 分位數截尾；類別使用 One-Hot Encoding（低頻類別合併、drop first），再用 StandardScaler。全資料預處理後的完整模型有 42 個編碼特徵，並不等於原始 33 個欄位。

04 / MODELING

模型建立 · Modeling

使用 LinearRegression 建立 Baseline，並比較 EFS、RFECV、Lasso (L1)、Backward Elimination 與 SFS。固定特徵數實驗只比較 1–5 個編碼後特徵：EFS 從 8 個候選、SFS 從 15 個候選執行；各方法選完後以 LinearRegression 擬合。

五種特徵選擇方法（Feature Selection）

  1. EFS — Exhaustive Feature Selection（窮舉特徵選擇）：評估候選特徵的所有指定大小組合，以驗證誤差比較；計算成本隨候選數快速增加。
  2. RFECV — Recursive Feature Elimination with Cross-Validation（交叉驗證遞迴特徵消除）：反覆移除重要性較低的特徵，利用交叉驗證挑選數量；固定數量曲線使用 RFE 消除路徑。
  3. Lasso (L1) — Least Absolute Shrinkage and Selection Operator（L1 正則化）：透過係數收縮及趨近零進行特徵篩選；曲線依 LassoCV 係數排名取指定數量，再以線性迴歸重新擬合。
  4. Backward Elimination（向後消除法）：從完整候選集合逐步移除特徵，直到達到指定數量。
  5. SFS — Sequential Forward Selection（循序向前選擇）：從空集合開始，每一步加入最有助於模型表現的特徵，直到達到指定數量。

上述方法用於比較或挑選變數，最終預測模型使用 sklearn LinearRegression（普通最小平方法，OLS）；固定特徵數曲線與自動選擇方法結果應分開解讀。

05 / EVALUATION

模型評估 · Evaluation

以 random_state=42 將資料分為 80% 訓練（1,148 筆）與 20% 測試（287 筆）。固定特徵數曲線呈現訓練資料外層三折 CV 的 RMSE、R²；方法比較另列 CV RMSE／標準差／耗時，頂部顯示選定 Baseline 的保留測試集結果。RMSE 越低、R² 越高通常越好。

06 / DEPLOYMENT

成果部署 · Deployment

使用 Python（main5.py）離線執行訓練、交叉驗證與結果匯出，再以 GitHub Pages 靜態網站展示互動圖表、方法比較、特徵明細與 CSV 下載；瀏覽器不會即時重訓模型。

固定特徵數曲線由 main5.py 執行並匯出：EFS 從 8 個候選窮舉，SFS 從 15 個候選向前選取；RFECV 的固定數量版本使用 RFE，Lasso 依係數排名（同分以 OLS 係數排序），Backward 刪除至指定數量。所有組合最後均以 LinearRegression 擬合。內層選擇使用已前處理的資料，內層分數可能偏樂觀；外層 CV 會重新擬合整條 pipeline。負 R² 如實保留。

「方法比較與選取特徵」保留原始設定的六方法比較，其特徵數由各方法自動或既定規則決定，與上方固定 1–5 個特徵的曲線不同。頂部 Test RMSE／R² 為main5.py 訓練 CV 選出 Baseline 後的保留測試集結果；固定特徵數比較不改變該模型選擇。點選六方法表格可查看其特徵明細。

資料來源：ToyotaCorolla.csv（main5.py）。網站展示已計算結果；Python 模型於離線執行，不在瀏覽器內訓練。
