METHODOLOGY / LIMITATIONS

這個自訂實驗與原始範例有什麼不同？

原有 Cars 與 50 Startups 保留 Python sklearn 離線匯出的既有結果；本頁為可即時操作的瀏覽器端分析版本。EFS 先依訓練集單變量相關性預選最多 8 個候選；SFS 預選最多 12 個候選；Backward 逐步移除OLS 係數絕對值較小的特徵；RFECV 使用固定 k 的 RFE 係數淘汰路徑（不自動決定 k）；Lasso 透過 L1 係數排名，再由 OLS 重訓。與原 Python 實驗的內層選擇／參數規則不完全一致，結果不應視為完全相同。

安全限制：最多 3,000 筆有效分析資料、60 個原始欄位、40 個編碼後欄位、5 個特徵選取上限。類別超過 12 種的欄位不參與模型。EFS、SFS 是限制候選數的近似搜尋；訓練 CV 於已由整體訓練資料擬合的編碼特徵上執行，可能略為樂觀。正式報告可使用完整 sklearn Pipeline 在交叉驗證各折內重新擬合。
