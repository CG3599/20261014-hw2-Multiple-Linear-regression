CRISP-DM / SIX PHASES

實驗方法 · CRISP-DM 六大階段

Cross-Industry Standard Process for Data Mining（跨產業資料探勘標準流程）。兩個資料集使用同一分析框架，細節以各自的資料與實驗設定為準。

01 / BUSINESS UNDERSTANDING

商業理解 · Business Understanding

以研發費用（R&D Spend）、行政費用（Administration）、行銷費用（Marketing Spend）與公司所在州別預測 Profit（獲利），比較不同特徵組合對預測表現的影響。

02 / DATA UNDERSTANDING

資料理解 · Data Understanding

50 Startups 有 50 筆資料，目標欄位為 Profit。原始輸入共有 4 欄：三個連續數值欄位與 State 類別欄位；樣本量小，解讀測試結果需留意不確定性。

03 / DATA PREPARATION

資料準備 · Data Preparation

State 採 One-Hot Encoding 並移除基準類別（Florida），保留 State_California、State_New York；與三個數值特徵合計 5 個編碼後輸入特徵，避免含截距線性模型的完全虛擬變數共線性。

04 / MODELING

模型建立 · Modeling

以 sklearn LinearRegression 建立多元線性迴歸模型，對 1–5 個編碼後特徵分別比較 EFS、RFECV、LassoCV（L1）、Backward Elimination 與 SFS；曲線是在固定特徵數下重訓線性迴歸，不等同各方法自動決定最終特徵數的結果。

五種特徵選擇方法（Feature Selection）

  1. EFS — Exhaustive Feature Selection（窮舉特徵選擇）：評估候選特徵的所有指定大小組合，以驗證誤差比較；計算成本隨候選數快速增加。
  2. RFECV — Recursive Feature Elimination with Cross-Validation（交叉驗證遞迴特徵消除）：反覆移除重要性較低的特徵，利用交叉驗證挑選數量；固定數量曲線使用 RFE 消除路徑。
  3. Lasso (L1) — Least Absolute Shrinkage and Selection Operator（L1 正則化）：透過係數收縮及趨近零進行特徵篩選；曲線依 LassoCV 係數排名取指定數量，再以線性迴歸重新擬合。
  4. Backward Elimination（向後消除法）：從完整候選集合逐步移除特徵，直到達到指定數量。
  5. SFS — Sequential Forward Selection（循序向前選擇）：從空集合開始，每一步加入最有助於模型表現的特徵，直到達到指定數量。

上述方法用於比較或挑選變數，最終預測模型使用 sklearn LinearRegression（普通最小平方法，OLS）；固定特徵數曲線與自動選擇方法結果應分開解讀。
