BEHIND THE EXPERIMENT / CRISP-DM

從資料到預測，一步一步重現

以 Cross-Industry Standard Process for Data Mining 六階段說明這份資料如何處理、訓練、比較與展示。

06 STAGES
01
Business Understanding

定義問題

以公司投入的研發、行政、行銷成本和所在州別預測 Profit（獲利），找出哪些特徵對獲利預測較有用。

研究問題

只使用 R&D Spend 是否足夠？加入 Marketing Spend 或 State 能否降低預測誤差？

02
Data Understanding

認識資料

50_Startups.csv 共 50 筆；原始輸入 4 欄（R&D Spend、Administration、Marketing Spend、State），預測目標是 Profit。

欄位示例

R&D Spend 是研發支出，Marketing Spend 是行銷支出；State 為類別型，不能直接作為數字係數。

03
Data Preparation

類別轉換

把 State 做 One-Hot Encoding 並 drop first，以 Florida 為基準，產生 State_California 和 State_New York；三個支出欄位加兩個州別指示欄位，共 5 個輸入。

實際轉換

Florida → (0,0)、California → (1,0)、New York → (0,1)，避免帶截距的回歸出現完全虛擬變數共線性。

04
Modeling

訓練與特徵選擇

使用 sklearn LinearRegression 預測 Profit，分別利用五種 Feature Selection 建立固定 k=1–5 的特徵組合比較，另保留自動選取結果。

實際操作

EFS k=1 實際選到 R&D Spend；LassoCV k=2 選到 R&D Spend 和 Marketing Spend。五方法詳細操作如下。

MODEL SELECTION / 05 SCHEMES

五種特徵選擇，實際怎麼做？

以下以本頁資料欄位示範；標記「實際曲線」者為網站既有輸出，其餘為執行流程說明。

01
EFS窮舉特徵選擇

列舉 5 個編碼特徵的指定大小組合，選擇表現較佳的組合。實際曲線：k=1 為 R&D Spend；k=2 為 R&D Spend + Administration。

02
RFECV交叉驗證遞迴特徵消除

從五個編碼特徵開始逐次消除；自動 RFECV 以 CV 決定數量，固定 k 曲線則取 RFE 路徑。實際曲線：k=1 為 State_California；k=3 為 State_New York、State_California、R&D Spend。

03
Lasso (L1)L1 正則化特徵選擇

LassoCV 收縮係數，依排名選 k 個特徵；零值或同分可由標準化 OLS 排序，再用 LinearRegression 重訓。實際曲線：k=1 為 R&D Spend；k=2 為 R&D Spend + Marketing Spend。

04
Backward向後消除法

從 R&D、Administration、Marketing 與兩個州別指示變數開始，逐次移除特徵到 k 個。例：當 k=2，會從原本 5 個編碼欄位中消除 3 個，表格會列出最後保留的欄位。

05
SFS循序向前選擇

從零個特徵開始，逐輪比較加入 R&D、Administration、Marketing 或州別變數的效果。例：當 k=2，先選第一個特徵，再針對剩下四個候選試算第二個，保留評估較佳的組合。

05
Evaluation

以共同測試集比較

以 random_state=42 進行 80/20 切分：40 筆訓練、10 筆測試。所有固定 k 組合都用同一份保留測試集比較 RMSE 與 R²，特徵選擇只用訓練資料。

讀圖方式

EFS k=1 的 Test RMSE 約 7,714、R² 約 0.927；數值是本站固定切分的觀察結果，不代表所有資料切分都相同。

06
Deployment

發佈可互動報告

Python 離線運算後將特徵組合、RMSE、R² 與自動方法比較結果輸出到資料檔，由 GitHub Pages 展示。

使用方式

在頁面切換方法與特徵數、點選曲線或表格查看選取欄位，再下載 CSV；網站不即時重訓。
