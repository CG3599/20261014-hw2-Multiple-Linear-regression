BEHIND THE EXPERIMENT

如何閱讀這份結果？

01 / CRISP-DM

從規格預測售價

預測目標為 Retail Price，排除 Dealer Cost。由 Name 擷取品牌、修正品牌名稱；11 個數值欄位搭配 Brand、Type。無效的零值轉為缺值，AWD 與 RWD 除外。

02 / TRAINING PIPELINE

在訓練折內前處理

每個外層訓練折重新擬合中位數／眾數補值、One-hot 編碼、StandardScaler 與特徵選擇。低頻類別依 min_frequency = 3 合併，編碼移除首個類別。

03 / FEATURE COUNT

比較特徵數與驗證表現

80% 訓練、20% 測試，random_state = 42。曲線比較五種方法各自選取 1–5 個特徵時，訓練資料外層三折 CV 的平均 RMSE 與 R²；不使用測試集。RMSE 越低越好，R² 越高越好。表格特徵來自完整訓練集，各折實際選取的特徵可能不同。

固定特徵數曲線採用 cars_feature_curves.py：EFS 從 8 個候選窮舉，SFS 從 15 個候選向前選取；RFECV 的固定數量版本使用 RFE，Lasso 依係數排名（同分以 OLS 係數排序），Backward 刪除至指定數量。所有組合最後均以 LinearRegression 擬合。內層選擇使用已前處理的資料，內層分數可能偏樂觀；外層 CV 會重新擬合整條 pipeline。負 R² 如實保留。

「方法比較與選取特徵」保留原始設定的六方法比較，其特徵數由各方法自動或既定規則決定，與上方固定 1–5 個特徵的曲線不同。頂部 Test RMSE／R² 為原始訓練 CV 選出 SFS 後的保留測試集結果；固定特徵數比較不改變該模型選擇。點選六方法表格可查看其特徵明細。

資料來源：uwdata/draco · cars.csv。網站展示已計算結果；Python 模型於離線執行，不在瀏覽器內訓練。
