BEHIND THE EXPERIMENT

如何閱讀這份結果？

01 / CRISP-DM

從規格預測售價

預測目標為 Retail Price，排除 Dealer Cost。由 Name 擷取品牌、修正品牌名稱；11 個數值欄位搭配 Brand、Type。無效的零值轉為缺值，AWD 與 RWD 除外。

02 / TRAINING PIPELINE

在訓練折內前處理

每個外層訓練折重新擬合中位數／眾數補值、One-hot 編碼、StandardScaler 與特徵選擇。低頻類別依 min_frequency = 3 合併，編碼移除首個類別。

03 / MODEL SELECTION

先選模型，再看測試

80% 訓練、20% 測試，random_state = 42。依外層 3 折的平均 RMSE 選出方法，再用完整訓練集擬合；僅對最佳方法評估保留測試集。

忠實呈現 main2.py 的原始方法設定：EFS 先以全訓練折的 F 分數篩選 8 個候選，再搜尋 1–3 個特徵；SFS 從前 15 個候選選出 8 個。內層選擇使用已前處理的資料，內層分數可能偏樂觀；外層 CV 仍會重新擬合整條 pipeline。特徵數依各方法自動或既定規則決定。R² 可為負值，線性模型也可能產生負售價預測；網站保留原始結果，不調整或裁切。

資料來源：uwdata/draco · cars.csv。網站展示已計算結果；Python 模型於離線執行，不在瀏覽器內訓練。
